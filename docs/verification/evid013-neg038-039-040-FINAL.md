## Formulas (implemented independently, same references as original)

| Metric | Reference | Implementation |
|--------|-----------|----------------|
| Sharpe | Sharpe (1994) JPIM | `mean(pnl_pct) / std(pnl_pct, ddof=1)` |
| Sortino | Sortino & van der Meer (1991) | `mean(pnl_pct) / sqrt(E[min(pnl_pct,0)²])` |
| MaxDD | de Prado (2018) p.97 | `(equity_curve − running_max) / running_max × 100` |
| Calmar | Young (1991) | `total_return_pct / abs(max_dd_pct)` |
| VaR 95% | Basel II §IV.A | `-percentile(pnl_pct, 5)` |
| CVaR 95% | Acerbi & Tasche (2002) | `-mean(pnl_pct[pnl_pct ≤ −VaR₉₅])` |

`pnl_pct` (% per trade) used for Sharpe/Sortino/VaR/CVaR.
`pnl` ($ per trade) used for MaxDD/Calmar (equity curve, account_start = $20,000).
