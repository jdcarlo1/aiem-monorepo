# Directive — Dual Scheduler Check

## Background
Codebase has TWO independent APScheduler `BackgroundScheduler` instances:
- `main.py` — live Flask app scheduler (`premarket_scan`, `morning_scan`, `outcomes_update`, etc.)
- `aiem_process.py` — separate scheduler inside `def main()`, gated by `if __name__ == "__main__"` (`aiem_warmup`, `aiem_premarket_scan`, `aiem_open_watcher`, `aiem_nightly_learn`, etc.)

`main.py` does not import `aiem_process.py`. This only matters if the latter is deployed/run as its own live process.

## Required findings
1. Is `aiem_process.py` currently deployed and running as a separate process (check Replit workflow/run config, Procfile-equivalent, or process list)? Yes/no, with the raw config/process listing shown.
2. If yes: list every table each scheduler's jobs read/write (grep both files for `.execute(`/table names). Flag any table touched by both.
3. If any overlap exists: for each shared table, confirm whether the two schedulers' jobs can run in the same time window (compare CronTrigger hours/minutes across both files) and whether either has a claim/lock mechanism preventing double-write (like the `try_claim` pattern already fixed once in `aiem_paper_recovery.py`).
4. If `aiem_process.py` is NOT currently deployed: confirm via git log / deployment config when it was last active, and state plainly that it's dead code.

## Evidence required (standing checklist — full, not abbreviated)
- Raw terminal output for every claim; raw grep/sed for any code-location or behavior claim — no paraphrasing.
- Raw process-listing / deployment-config output proving live vs. not-live status — not a narrative claim.
- Before/after sha256 for any file changed.
- Raw SQL + full result set for any DB query run as part of this check.
- sha256 cross-check: `tools/verified_run.sh` and `artifacts/stock-scanner-api/verify_chain.sh` against current canonical values on file.
- All evidence-producing commands run through `verified_run.sh`; paste `verify_chain.sh` output before declaring done.
- State plainly if any item can't be backed by real output — no padding.
- No fixes yet — this is a diagnostic-only directive. Report findings, do not modify scheduler code.
