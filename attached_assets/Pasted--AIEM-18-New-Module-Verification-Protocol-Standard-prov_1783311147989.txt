# AIEM — 18 New Module Verification Protocol

**Standard: prove it, don't tell me.** No narrative summaries, no "✅ working" checklists without evidence. Every answer below must come with raw terminal output, actual variable values, SQL query results, or a git diff showing the wiring line. If a module cannot produce that evidence, say so explicitly — do not fill the gap with a description of what it *should* do.

For every module below, answer all four questions with real output:

1. **Called from where?** Show the exact file + line number where this module is instantiated and invoked from the live trading pipeline (not from a standalone test script).
2. **Real input, printed.** Run it once with a live/paper trading signal (not a synthetic ticker) and paste the actual input object passed in.
3. **Real output, printed.** Paste the actual output object it returned for that input.
4. **Downstream consumption.** Show the exact line of code where the *next* module in the chain reads this module's output — prove it isn't computed and discarded.

## Cross-Cutting Integration Checks (do these last, after all 18 pass individually)

1. **Full chain trace.** Take ONE real signal from entry to trade decision. Show it passing through every module in order (EdgeFilter stack → V2 system → Intelligence layer) with real intermediate output at every single hop, not a summary of the chain.

2. **Silent-failure sweep.** For every module that has a guard/filter (ExpectancyEngine's hard block, RegimeEngine's filter, OverfitDetector's flag, AdaptiveMarketLayer's routing), confirm the guard raises/logs loudly on unexpected input rather than silently no-op'ing — per the `update_policy()` bug found in AIEM's PPO module. Grep for `if X not in Y: return` patterns across all 18 modules and list every hit.

3. **Dead code check.** For each of the 18 modules, confirm it is imported and instantiated somewhere in the actual production entry point (not just defined and never called). List any module that fails this check.

4. **No test-only wiring.** If a module only gets called from a test file and never from the live/paper trading pipeline, flag it explicitly as "not yet wired to production" — do not report it as working.

Report format: one row per module (18 rows) with columns: Module | Wired to production? (Y/N + file:line) | Real output shown? (Y/N) | Downstream consumption proven? (Y/N) | Notes/red flags.
