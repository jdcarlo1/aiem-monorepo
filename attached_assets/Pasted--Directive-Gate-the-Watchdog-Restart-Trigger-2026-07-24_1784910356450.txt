Implement an atomic, DB-backed daily cap enforced inside `/run-scan` before:

threading.Thread(...).start()

The cap must:

- survive process restarts
- cover watchdog and GitHub Actions together
- count accepted scan triggers, not only completed scans
- reject excess requests before execution
- use a configurable maximum

2. KILL SWITCH

Requirements:

- Joel can enable or disable it
- watchdog can read it but cannot clear or override it
- disabled or unreadable state must block execution
- block must be logged with timestamp, source, and reason
