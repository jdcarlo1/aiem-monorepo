**Context:** `_evaluate()` in `aiem_discovery_engine.py` computes `baseline_wr` but never uses it in any conditional. Candidates currently only need to pass the overfit-gap check and the 45% OOS win-rate floor to become `status='pending'`. Add a minimum-edge-over-baseline requirement.

**Where:** In `_evaluate()`, insert the new check after line 530 (`oos_stats = _compute_stats(...)`) and before line 533 (the `_check_overfit(...)` call).

## Logic to add

```python
edge_pp = round(oos_stats["win_rate"] - oos_stats["baseline_wr"], 2)
if edge_pp < _MIN_EDGE_OVER_BASELINE:
    return {
        ...  # same return shape as other rejection paths
        "status": "rejected",
        "rejection_reason": f"no_edge: OOS win rate beats baseline by only {edge_pp}pp (need {_MIN_EDGE_OVER_BASELINE}pp)",
    }
```

Near `_OVERFIT_GAP_THRESHOLD` and `_MIN_IS_TRADES`:

```python

This is a minor efficiency point, not correctness-critical — either order is acceptable as long as it's stated explicitly.
