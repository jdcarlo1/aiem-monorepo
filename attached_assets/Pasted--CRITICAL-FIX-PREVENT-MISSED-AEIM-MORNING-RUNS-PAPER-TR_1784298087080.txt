1. INDEPENDENT BACKUP HOST
- Create a standby worker outside the primary Replit VM.
- It must be able to run the Polygon scan and full AEIM pipeline.

- Run outside the primary VM.

- Store the daily Polygon scan, candidate seed, and pipeline run in Postgres before they are due.

  SCHEDULED, CLAIMED, RUNNING, COMPLETED, NO_TRADE, FAILED.

- Do not seed from an empty table and stop.

5. DUPLICATE PROTECTION
- Primary and backup may both see the job, but only one may claim it.
- Use a Postgres lock, lease, and unique idempotency key.
- Prevent duplicate paper trades and duplicate pipeline effects.
