# Module B Remediation — Wire Real Short Interest Data (Polygon)

**Context:** Module B (Short Squeeze Reversion) was built and backtested using proxy conditions
(RVOL + close_strength + range_pct) because real short-interest data was marked
`NOT_IMPLEMENTED`. The honest backtest result was WR=40.6%, avg_ret_3d=-1.86%, p=0.9999 —
below baseline, correctly logged as `status='hypothesis'` and excluded from live paper trading.

**Confirmed:** the existing Polygon plan ($29/month Stocks Starter) includes the Short Interest
API. No new account, API key, or vendor integration is needed — this uses the existing Polygon
credentials already wired into the system.

**What the Polygon Short Interest API provides:**
- Total shares sold short but not yet covered
- Average daily trading volume
- Calculated days-to-cover (DTC) ratio
- Data on a bi-monthly cadence (FINRA settlement-date reporting schedule), with historical
  records back to December 29, 2017

**Known limitation to carry forward honestly:** this is bi-monthly data, not real-time or daily.
It won't capture intraday short-interest shifts, but it is a real, verifiable number replacing
a proxy guess — a meaningful upgrade even with the reporting-lag limitation. This limitation
should be logged in the module's output, not hidden.
