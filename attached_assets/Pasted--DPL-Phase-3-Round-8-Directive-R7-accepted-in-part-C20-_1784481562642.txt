# Standing requirements — apply to every item above

**Raw evidence.** No task is complete on description alone. Required: (1) raw terminal
output of actual execution, including raw `grep -n` / `sed -n` for ANY claim about code
location, line numbers, call chains, or whether a pattern exists — never paraphrase;
(2) exact before/after diff; (3) sha256 before/after for every file changed this session;
(4) raw SQL + full result set for any DB claim. If you cannot produce evidence for a
claim, say so in one line. Narrative claims of "fixed"/"tested"/"confirmed" are rejected.

**Evidence chain.** Run all evidence-producing commands through `verified_run.sh`.
Validate with `verify_chain.sh` and paste its output before declaring complete. Paste raw
`sha256sum` for BOTH `tools/verified_run.sh` and `artifacts/stock-scanner-api/verify_chain.sh`,
checked against canonical `ba7faf8d…` and `ca7896c7…`. Mismatch = validator drift =
output rejected regardless of content.

**Data immutability.** Never delete, truncate, drop, or overwrite any row, table, or file
— including data you created or label test/synthetic/cleanup — without explicit prior
approval in this session. State what you want to delete and why, wait, then log it. Any
unapproved deletion is a violation to report, not self-correct.

**No hardcoded values.** List every numeric/decision literal in new code; for each, raw
`grep`/`sed` of the line plus a one-line trace to its live source. "Wired later" is not
acceptable at completion. Every conditional gate introduced needs a negative control
showing it blocks under the failing condition.

**Math/quant correctness.** Where formulas are involved: state the reference formula
before running, use externally-derived known-answer vectors, cross-check by a second
method where feasible, and mutation-check that the test catches a deliberately broken value.

**Verifier PASS is not execution authorization.** A passing check proves the code did what
it was written to do. C01–C27 only test what someone thought to test. Do not treat any
PASS count as clearance for autonomous operation.

**Output format.** Raw command results only. No restated context, banners, dividers,
narrative commentary, or "representative" sample rows. Test suites: final summary line
only. Data changes >10 rows: `\copy` CSV, never inline. Close with `git diff HEAD --stat`
and `git status --porcelain`.
