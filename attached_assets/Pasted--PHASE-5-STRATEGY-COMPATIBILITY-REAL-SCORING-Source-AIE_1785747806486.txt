Scope: Options Engine only. Paper trading only.

## Requirements
1. Before scoring the 155 strategies, filter by direction, confidence,
   volatility regime, expected move, event context, horizon, liquidity,
   portfolio exposure, defined-risk status. Implement the minimum mappings
   listed in §7 (bullish/bearish x low/high IV, neutral, event cases).
   Only AUTONOMOUS + defined-risk strategies may paper-execute. Keep
   NO_TRADE as a scored candidate — winner must beat it by a configured margin.
2. The existing scorer must receive REAL values (not hidden defaults) for:
   pattern_score, pm_intel_score, mtf_alignment_score, iv_rank, iv_percentile,
   market_regime, volatility_regime, liquidity_score, signal_quality,
   direction_confidence, expected_slippage, fill_probability.
   Persist score inputs, weights, penalties, and output.

## Evidence required (master §14 items 6, 7, 15)
- Item 6/7: one real high-IV case and one real low-IV case showing the
  correct strategy family selected per §7's mapping table.
- Item 15: one real case where NO_TRADE outscores every built strategy —
  raw scores for NO_TRADE vs. the candidates, showing the configured margin.
- For each of the 12 score inputs: grep + one live example proving it's a
  real computed/fetched value reaching the scorer, not a default.
