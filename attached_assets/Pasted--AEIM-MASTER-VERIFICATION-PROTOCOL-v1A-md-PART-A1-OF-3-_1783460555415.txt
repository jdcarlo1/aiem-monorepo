## Architecture & Wiring Verification

Version 1.0

====================================================================

# PURPOSE

This document is NOT intended to verify trading performance.

Its purpose is to verify that every component of the
AEIM architecture has been correctly implemented,
connected, ordered, and validated.

No module should be assumed to be working.

Every module must provide objective proof.

====================================================================

# MASTER REQUIREMENT

Replit must provide engineering evidence,
not simply answer "yes."

Every verification response should include:

• Code location
• Files involved
• Function names
• Inputs
• Outputs
• Execution order
• Database tables used
• Verification logs
• Test results

Statements without evidence are not sufficient.

====================================================================

# SYSTEM BOUNDARY VERIFICATION

Verify the following:

✓ AEIM is completely independent.

✓ AEIM loads Polygon directly.

✓ AEIM does NOT require the stock scanner.

✓ AEIM continues operating if the stock scanner is offline.

Required Proof

Show

Entry point

Scheduler

Discovery function

Polygon connection

Discovery pipeline

Failure test

PASS

AEIM still discovers stocks.

FAIL

AEIM depends on scanner.
