STANDING VERIFICATION REQUIREMENTS (apply in full to every item)
============================================================
- No item is complete based on description alone.
- Raw evidence required per item: raw grep/sed output for any code-location
  or behavior claim (never paraphrased); raw SQL query + full result set;
  before/after sha256 for any changed file; verified_run.sh +
  verify_chain.sh output.
- sha256 cross-check of tools/verified_run.sh and
  artifacts/stock-scanner-api/verify_chain.sh against current canonical
  values required before any evidence from this phase is accepted.
- Standing Data Immutability Rule: no delete/truncate/drop/overwrite of any
  row, table, or file — including test/synthetic data — without Joel's
  explicit prior approval in that session.
- Every negative control / conditional gate in this phase must be run and
  its output pasted; a gate not shown blocking under the failing condition
  is not verified.
- Quant/statistical items: independent known-answer test vectors (not
  agent-invented), stated formula/reference before running, cross-check via
  a second method where feasible, mutation check proving the test isn't
  vacuous.
- Output format: raw command output only — no narrative, no restated
  headers, no "representative" sample rows, no re-verification of anything
  unchanged this session.
- Each item receives exactly one verdict: PASS / FAIL / NOT_IMPLEMENTED /
  IMPLEMENTED_NOT_VERIFIED / PARTIAL.
- This phase does not close until every item has a verdict and every PASS
  has raw evidence attached.
