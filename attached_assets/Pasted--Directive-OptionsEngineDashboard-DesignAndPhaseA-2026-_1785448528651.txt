## Design system (applies once build starts)
Target: hedge-fund/institutional terminal quality, not a retail dashboard template.

Visual:
- Deep charcoal/navy background, not pure black
- Monospace/condensed type for all numeric data
- Hairline dividers, no card shadows, dense information layout
- One restrained accent color for live-state changes only

Differentiating features (build only if backend data actually supports it — verify first, no fabricated UI):
1. Live decision lineage view — visual trace of a candidate through data guard → risk gate → position sizing → execution, sourced from the real audit/hash-chain tables
2. "Why this trade" panel — real gating logic + probability/EV that produced the decision, not a black-box score
3. Live probability calibration reliability diagram, sourced from real calibration data
4. Visible evidence-chain/verification status indicator on live decisions (sealed/verified/sha256-anchored)

Technical:
- Real push (WebSocket/SSE) for the live-decisions feed — polling is not acceptable for this screen
- Command-palette navigation (Cmd+K style)
- Canvas/WebGL charts for Greeks/P&L views, not laggy DOM charts
