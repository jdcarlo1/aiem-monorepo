## Required evidence (raw output only — no paraphrasing, per standing protocol)

1. **Git history per path** — for each of the 5 files, paste raw output of:

2. **File timestamps** — raw `stat` output (mtime, ctime) for all 5 files

3. **Live reference trace** — raw `grep -rn` output across the entire codebase
   for every place `verified_run.sh` and `verify_chain.sh` are invoked or
   sourced (by exact path, not just filename). Identify which path(s) are
   actually called by production code vs. only referenced in docs/comments/

4. **Git tracking status** — raw `git status` / `git check-ignore -v` output
   for each of the 5 paths, to confirm whether each is tracked, untracked, or
   gitignored (e.g. `.local/` is often a local-only scratch dir — confirm,
   don't assume)

5. **Pairwise diffs** — raw `diff` output between:
   - .local/verified_run.sh vs tools/verified_run.sh
   - .local/verify_chain.sh vs tools/verify_chain.sh vs artifacts/stock-scanner-api/verify_chain.sh

6. **Origin of the cited hash** — search commit history / commit messages /
   any changelog or directive log for where 72824bfe...24abd and
   7294abeb...1fbec7 were originally recorded, to establish what version of
   the script those hashes actually correspond to (if recoverable)

## Deliverable
A findings table only — path, tracked/untracked, last modified, called by
production (Y/N), diff summary vs. the other copies — plus a flagged
