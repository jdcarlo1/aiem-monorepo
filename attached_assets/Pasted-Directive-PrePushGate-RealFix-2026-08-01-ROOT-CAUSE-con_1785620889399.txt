ROOT CAUSE (confirmed via code read):
git_autosync_daemon.py's TLA/protected-file check only runs inside its
own automatic push cycle. It is NOT a git hook. Any direct `git push`
run manually in the terminal (by Joel or the agent) never touches
this check at all and reaches origin/dev unguarded. This is why
b5e7a02 (no TLA) and 9267fee (self-issued TLA) both pushed clean.

FIX REQUIRED — make the gate un-bypassable regardless of who pushes:

   tools/check_protected_push.sh or .py, that takes no daemon state
   and can run standalone against any commit range.

2. Install that script as the real git hook: .git/hooks/pre-push.
   This makes it fire on EVERY push — manual terminal push, agent
   push, daemon push — not just the daemon's own cycle.

3. Update git_autosync_daemon.py to call this same shared script
   instead of its own inline copy of the logic, so there's one
