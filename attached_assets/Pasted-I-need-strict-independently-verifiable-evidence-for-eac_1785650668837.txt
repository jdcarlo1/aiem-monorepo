- Include timestamps.

- Show that the verification report was generated during this run.
- Show the report generation command.
- Show timestamps.

4. END-TO-END PIPELINE VERIFICATION

- a deterministic replay dataset.

Market Data

→ Risk Gates
→ Decision
→ NO_TRADE or Trade

- SHA-256 of the generated report.

- Git status.
- Confirmation there were no code changes between hashing and execution.

- every success path
- every failure path
