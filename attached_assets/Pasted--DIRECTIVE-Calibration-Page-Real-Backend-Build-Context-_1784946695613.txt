## Task
Build a REAL backend endpoint for the Calibration page. No gaps, no shortcuts,
no fabricated data anywhere in the chain.

2. Expose real data only: Brier score, calibration curve (predicted probability

   request), STOP and report the specific blocker before writing the route —
   do not fake a synchronous response.
4. Build the frontend page only after the backend route is confirmed working
   with a real API response (same pattern as Performance/Probability).
