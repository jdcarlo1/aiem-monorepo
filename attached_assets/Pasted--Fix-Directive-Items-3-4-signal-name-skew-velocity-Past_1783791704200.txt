## ITEM 4 — `skew_velocity` / `options_structure_scan` scanner has no scheduler entry

**What it needs to be wired into:**
The existing job scheduler in `main.py` — the same mechanism used to register the other ~110 scheduled jobs already running (macro engine, regime detection, etc.). This is not a new subsystem; it's a missing registration in an existing one.

**Fix instructions to give the agent:**

1. Find the scanner function that's supposed to populate `options_structure_scan`:

   ```
   grep -rn "def.*options_structure" .
   ```

   ```
   grep -n "add_job\|scheduler.add" main.py
   ```
3. Add the missing registration for the options structure scanner using the same pattern (same scheduler object, comparable interval/cadence — ask what cadence makes sense given how often options structure data should refresh, don't just copy an arbitrary interval).
4. Confirm the job actually runs: after deploying/restarting, grep the application logs for the job's start/completion log lines, or query:
   ```sql
   SELECT COUNT(*), MAX(created_at) FROM options_structure_scan;
   ```
