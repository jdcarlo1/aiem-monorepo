# PHASE 2 — SIGNAL ENGINE
Source: AIEM_OPTIONS_AUTONOMY_MASTER_DIRECTIVE.txt §2, §4
Target: aiem_options_signal_engine.py (create only if absent), aiem_pattern_engine.py
Depends on: Phase 1 CLOSED (status enum + universe ranking live)
Scope: Options Engine only. Paper trading only.

## Requirements
1. Implement SignalResult exactly as specified (frozen dataclass, all fields
   listed in §2) — one result per ticker.
2. Wire VWAP, EMA/SMA, ADX, RSI, MACD, ATR, Bollinger position, RVOL, volume
   profile, support/resistance, GARCH, VPIN, Hurst, patterns, premarket, MTF,
   sector strength, breadth, regime into SignalResult's components. Do not
   claim a component is wired unless its runtime output actually reaches
   SignalResult — this must be shown, not asserted.
3. Directional decision: compute bullish/bearish/neutral evidence; require
   minimum signal_quality + confidence; conflicting or missing mandatory
   evidence => NEUTRAL/NO_TRADE. Persist every component + timestamp.
4. Repair aiem_pattern_engine.detect_for_ticker for: candlestick, chart
   structure, harmonic, Wyckoff/VPA, Elliott Wave (only if genuinely
   implemented — do not fake it). No broad exception may produce
   pattern_score=0.5. Persist pattern, direction, confidence, timeframe,
   invalidation level.

## Evidence required (master §14 items 3, 4, 5, 9, 10, 11)
- Items 3/4/5: one real bullish, one bearish, one neutral case — raw SignalResult
  row for each, tracing which components drove the direction.
- Item 9: one real premarket-component score traced to its live input.
- Item 10: one real MTF-alignment score traced to its live input.
- Item 11: one real pattern score traced to a genuine detected pattern (not 0.5).
- Item 8 (missing-module case): force one module to fail, show FAILED status
  propagates to INSUFFICIENT_DATA/NO_TRADE, not a silent default.

## Out of scope this phase
Volatility calcs, chain gate, scoring/strategy mapping, triggers, autonomy
cadence, position management — Phases 3-8.
