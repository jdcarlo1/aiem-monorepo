## STANDING VERIFICATION BLOCK (applies to both directives)

No task is complete based on description alone. Agent must provide:

1. Raw terminal output of actual execution.
2. Exact before/after file diff.
3. sha256 hash before/after for any changed files.
4. Raw SQL query + full result set if a database is involved.

Narrative or paraphrased claims of "fixed" or "tested" without pasted evidence
are rejected. Agent must explicitly state if it cannot produce a required
evidence item.

## STANDING DATA IMMUTABILITY RULE (applies to both directives)

Agent may never delete, truncate, drop, or overwrite any row, table, or
file — including data it created itself or labels "test," "synthetic," or
"cleanup" — without explicit prior approval in that session. Agent must state
what it wants to delete and why, wait for approval, then log it. Any
unapproved deletion is a protocol violation to report, not self-correct.
