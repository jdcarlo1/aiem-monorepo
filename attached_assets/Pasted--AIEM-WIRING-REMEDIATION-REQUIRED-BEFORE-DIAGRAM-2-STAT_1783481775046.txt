### Install Diagram 2 as the permanent AEIM Inter-Module Communication & Verification Layer

Diagram 2 is not a replacement for the existing architecture. Diagram 2 is
the integration layer that permanently connects all verified components
into one closed-loop autonomous system.

### Required Connections

```
Master Orchestration Layer
        │
        ▼
Inter-Module Communication Bus
        │
        ├── Candidate Intake
        ├── Discovery Layer (existing)
        ├── Analysis Layer (existing)
        ├── Market Regime (existing)
        ├── Specialist Council (existing)
        ├── Risk Manager (existing)

        ├── Paper Trading (existing)
        ├── Observability/Audit (existing)
        ├── Outcome Tracker (existing)
        ├── Attribution (existing)
        ├── Learning Systems (existing)
        ├── Memory System (existing)
        └── Feedback Loop → Master Orchestrator
```

### Communication Rules

- Every module communicates only through the Communication Bus.
- Every module receives: `candidate_id`, `execution_plan_id`, `trace_id`,
  market context, upstream outputs.
- Every module returns: `module_name`, `status`, `confidence`, `score`,
  `evidence`, `tools_used`, `errors`, `timestamps`.
- The Communication Bus records every transfer.
- The Orchestrator remains the only controller of execution order.
- Diagram 2 never replaces existing decision logic.
- Diagram 2 only: routes, verifies, traces, logs, connects, feeds learning
  back.

### Learning Loop

```
Outcome Tracker
        │
        ▼
Attribution
        │
        ▼
Learning Systems
        │
        ▼
Memory
        │
        ▼
Master Orchestrator
```

Every completed trade must update future decisions through this loop.
