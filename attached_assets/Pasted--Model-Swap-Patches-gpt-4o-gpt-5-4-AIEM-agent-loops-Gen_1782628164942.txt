# Model Swap Patches: gpt-4o -> gpt-5.4 (AIEM agent loops)

General rule applied to every patch below, based on your own working gpt-5.4
calls (lines 29311, 37491):
  - model: "gpt-4o" -> "gpt-5.4"
  - max_tokens=N -> max_completion_tokens=N
  - temperature=X line REMOVED (your working gpt-5.4 calls never set it -
    if gpt-5.4 is a reasoning-tier model it may reject a custom temperature
    entirely; safest to drop it and let it use the default)

TEST ORDER: apply patch #4 (morning scan) first, run it once, confirm it
completes normally and saves predictions. Only then apply the rest.
