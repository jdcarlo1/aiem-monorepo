SECTION 5 — IMMUTABLE EVENT HASHING
======================================================================

Use deterministic canonical serialization.

Recommended rule:

payload_sha256 =
SHA256(canonical_json(event_payload))

event_sha256 =
SHA256(
    canonical_json(provenance_metadata)
    + payload_sha256
    + previous_event_sha256
)

Canonical JSON must use:

- deterministic key ordering,
- UTF-8,
- consistent null handling,
- consistent timestamp formatting,
- no unstable memory addresses,
- no random whitespace,
- no secrets.

Store the previous hash and current hash.

Create a validation function that can:

- validate a single event,
- validate a complete trace,
- identify the first broken event,
- identify the altered field,
- identify missing sequence numbers,
- detect duplicate event IDs,
- detect duplicate idempotency keys,
- detect impossible timestamp ordering.

Historical evidence must be append-only.

Corrections must create a new corrective event; they must not overwrite
historical evidence.
