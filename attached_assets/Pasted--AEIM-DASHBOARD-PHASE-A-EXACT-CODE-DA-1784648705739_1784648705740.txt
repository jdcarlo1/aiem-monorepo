4. DATA CLASSIFICATION

Classify every dashboard value as one of:

• STORED
Value is already stored in PostgreSQL.

• CALCULATED_ON_REQUEST
Value exists in code but is not stored.

• LIVE_STREAM
Value is generated continuously or from events.

• HISTORICAL
Value is available only from prior records.

• DERIVED
Value must be calculated from verified stored fields.

• NOT_IMPLEMENTED
No authoritative source exists.

• IMPLEMENTED_NOT_VERIFIED
Code exists but runtime proof is missing.

• VERIFIED
Code, database and runtime evidence all exist.

Do not classify requested functionality as VERIFIED based only on file names or comments.
