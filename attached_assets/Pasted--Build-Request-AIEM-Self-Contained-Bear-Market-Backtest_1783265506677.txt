# Build Request: AIEM Self-Contained Bear Market Backtest Module

## Directive
Do not run this backtest manually yourself and report the numbers to me. Instead, build a permanent, reusable backtest function directly into AIEM's own codebase. AIEM itself must execute the analysis and generate the output. Your job is to build the capability once, trigger it, and relay AIEM's own generated results back to me — not to do the calculation work in an ad hoc script outside AIEM.

This needs to be a standing capability inside AIEM (e.g. `run_backtest(start_date, end_date, signal_params)` or similar), not a one-off query, so it can be re-run in the future without rebuilding it.

## What the function must do
Given a date range and signal parameters, AIEM must independently:
1. Pull SPY daily price history for that range from `polygon_market_daily`
2. Apply the panic exhaustion entry logic: `spy_20d_ret < -5.0` (crossing below)
3. Simulate every signal instance in that range with:
   - 11 trading day hold period
   - -8% stop-loss from entry (specify intraday or close-based)
4. Compute and return: n (signal count), win rate, average return (including stopped-out trades, not excluding them), worst single trade, number of stop-outs, max consecutive losing signals, and total cumulative return if every signal were taken sequentially with equal sizing

## Test it against these periods once built
- 2000-2002 dot-com bear market
- 2007-2009 financial crisis
- 2022 grinding bear market
- 2020 COVID crash (secondary comparison — flag that this recovered unusually fast)

If `polygon_market_daily` doesn't have SPY data that far back, AIEM's own output must state that explicitly (earliest available date), not substitute another ticker or estimate.
