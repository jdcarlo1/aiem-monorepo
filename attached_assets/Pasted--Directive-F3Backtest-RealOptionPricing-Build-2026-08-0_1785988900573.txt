```python
def get_atm_option_ticker(spot_price, expiration_date, is_call):
    """SPY strikes are $1 increments. ATM = nearest whole dollar."""
    strike = round(spot_price)
    strike_str = f"{int(strike * 1000):08d}"   # Polygon format: 8 digits, 3 decimal implied
    cp = "C" if is_call else "P"
    exp_str = expiration_date.strftime("%y%m%d")
    return f"O:SPY{exp_str}{cp}{strike_str}"


def fetch_option_price_at(option_ticker, date_str, target_minute):
    """Returns the close of the 1-min bar nearest target_minute, or None if no data."""
    url = f"https://api.polygon.io/v2/aggs/ticker/{option_ticker}/range/1/minute/{date_str}/{date_str}"
    params = {"adjusted": "true", "sort": "asc", "limit": 5000, "apiKey": POLYGON_API_KEY}
    resp = requests.get(url, params=params, timeout=30).json()
    bars = resp.get("results") or []
    if not bars:
        return None
    # convert each bar's "t" to ET minute-of-day same way organize_bars_by_day does,
    # pick the bar whose minute is closest to target_minute
    best = min(bars, key=lambda b: abs(_et_minute(b["t"]) - target_minute))
    return float(best["c"])
```

In `run_f3_backtest`, for each trade that currently computes
`atm_est` / `leverage` / `option_ret`, instead:


SPY 0DTE expiration = same calendar day as the trade date (SPY has
had daily expirations since 2022) — confirm this is still true for
every date in the backtest window, don't assume.
