# Directive — Implement Structural Guardrails

Goal: stop relying on manual review to catch duplicate files, hash drift, and untested end-to-end flows. These checks must block bad states automatically, not just get reported after the fact.

- `guardrails/check_duplicate_files.sh` — fails if any protected filename exists at >1 path
- `guardrails/canonical_hashes.json` — single source of truth for expected file hashes
- `guardrails/verify_canonical_hashes.sh` — fails on any drift from the registry
- `guardrails/pre-commit` — local git hook wiring both checks before every commit
- `.github/workflows/verification-ci.yml` — CI pipeline, blocks merge on failure, runs nightly too
